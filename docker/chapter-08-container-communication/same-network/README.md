# Container Communication — Shared Network (Chapter 08)

This folder demonstrates how containers can communicate when they are attached to the same Docker network.

The server and client are started on a user-defined bridge network, which allows DNS-based service discovery.

---

## How to run

```bash
cd docker/chapter-08-container-communication/same-network/good
./run.sh
```

---

## Clean up

```bash
./clean.sh
```
