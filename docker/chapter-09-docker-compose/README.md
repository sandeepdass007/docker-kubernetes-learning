# Chapter 09 — Docker Compose

This chapter compares **manual container orchestration** with **Docker Compose**.

Two scenarios are included:

- `scenario-01-no-compose/` — run a server and client using raw `docker` commands, port mapping, and networks.
- `scenario-02-with-compose/` — achieve the same behavior using `docker compose`.

Each scenario is self-contained and explains the steps to run and clean up.

---

## How to start

Pick a scenario and follow its README:

```bash
cd docker/chapter-09-docker-compose/scenario-01-no-compose
# or
cd docker/chapter-09-docker-compose/scenario-02-with-compose
```
